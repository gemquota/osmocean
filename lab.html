04 / INTERPRETATION

What this lab proves

Standalone

Each upstream application can be launched independently. Fluid and Rapier have public hosted demos. Ultra-Water is launched from its actual source through a StackBlitz browser workspace because upstream does not publish a demo host.

Co-resident

Multiple independent renderers can be opened at once. This exposes browser compatibility, GPU memory pressure, frame pacing and mobile thermal limits.

Coupled

Not proven here. Real coupling requires shared state, explicit units and coordinates, fixed-step ownership, force exchange, and conservation/error tests. Cross-origin iframes cannot provide that integration.
