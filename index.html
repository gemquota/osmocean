02 LIVE UPSTREAM SIMULATION

2D PIC/FLIP fluid / jeantimex/fluid

UPSTREAM ENGINE
PIC/FLIP · STAGGERED MAC GRID · PRESSURE PROJECTIONOPEN UPSTREAM ↗

A real particle-grid fluid solver. Particle-in-cell / fluid-implicit-particle velocity transfer is coupled to a staggered MAC grid and pressure projection. Interact inside the simulation.

SOURCE + MIT LICENCE ↗

The solver runs from the upstream project's hosted build inside this page. It is not a locally rewritten Osmocean solver. Cross-engine body coupling is a separate integration task and is not claimed as complete.

03 SELECTED OPEN-SOURCE FOUNDATIONS
A / FLUID SOLVER

jeantimex / fluid

MIT-licensed browser fluid research: 2D PIC/FLIP and hybrid FLIP, 3D SPH and WebGPU PIC/FLIP, pressure projection and multiple renderers.

UPSTREAM REPOSITORY ↗
B / OCEAN RENDERER

Humpalumps / Ultra-Water

MIT-licensed Three.js ocean renderer with Tessendorf FFT cascades, shore breakers, foam, caustics, underwater rendering and buoyancy. Upstream currently ships as a local Vite demo, not a public hosted embed.

UPSTREAM REPOSITORY ↗
C / RIGID BODIES

Rapier

Open-source 3D rigid-body and collision engine with official JavaScript/WASM bindings. Intended to provide collision and constraint solving, not fluid mechanics.

04 OSMOCEAN'S RESPONSIBILITY

Integrate first.
Extend deliberately.

Osmocean owns the adapters and marine-specific layer: common units and coordinates, water-field queries, body-to-fluid coupling, distributed hydrodynamic loads, buoyancy, organism locomotion and ecosystem behaviour. It should not duplicate upstream fluid solvers or ocean rendering.
